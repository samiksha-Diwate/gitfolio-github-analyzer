# GitFolio 🚀

GitFolio is a GitHub Portfolio Analyzer built using:

- Java
- Spring Boot
- Thymeleaf
- GitHub REST API
- H2 Database

## Features

- Search GitHub users
- View repositories
- Analytics dashboard
- Charts and statistics
- Featured repositories

## Tech Stack

- Java
- Spring Boot
- Maven
- HTML/CSS
- Chart.js

## Future Improvements

- AI repo analysis
- Contribution heatmaps
- PDF export
- GitHub authentication
